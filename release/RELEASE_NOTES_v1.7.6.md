# Control Eléctrico para Android 1.7.6

- Barra inferior con acabado de cristal, etiquetas bajo cada icono y pestañas accesibles. Mejor contraste en modo diurno.
- Lecturas anteriores: solo se sugieren registros del mismo usuario con fecha estrictamente anterior. Cambiar de usuario ya no arrastra valores de otro medidor.
- El selector incluye todos los usuarios activos con medidor propio. Se impiden lecturas incompletas y duplicadas para un mismo usuario y periodo.
- Las exportaciones de CSV, JSON y PDF informan si se guardaron o si hubo un error de escritura.

Compatible con Android 10 o posterior. No modifica los registros existentes.
Esta versión actualiza Android. Las descargas de Windows y web siguen en [v1.7.5](https://github.com/Gwr4rd/Control-electrico/releases/tag/v1.7.5).
